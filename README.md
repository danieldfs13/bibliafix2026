# 📖 Bíblia Flix - Histórias Bíblicas para Crianças

## 🎯 Sobre o Projeto

O **Bíblia Flix** é um site interativo estilo Netflix criado especialmente para crianças, oferecendo histórias bíblicas em animações coloridas e narrações especiais. O projeto combina tecnologia moderna com conteúdo educativo religioso, proporcionando uma experiência envolvente e didática.

## ✨ Características Principais

### 🎨 Design e Interface
- **Layout estilo Netflix** com fundo preto elegante
- **Design responsivo** para desktop e mobile
- **Animações suaves** e transições fluidas
- **Cores vibrantes** e elementos infantis
- **Navegação intuitiva** com header fixo

### 📚 Organização do Conteúdo
- **Histórias organizadas por livros bíblicos**:
  - **Antigo Testamento**: Gênesis, Êxodo, 1 Samuel, Daniel, Jonas
  - **Novo Testamento**: Lucas, Marcos, João
- **Filtros interativos** por livro bíblico
- **Sistema de categorização** claro e educativo

### 🎬 Player de Vídeo Avançado
- **Player customizado** estilo Netflix
- **Sistema de progresso persistente** (salva no localStorage)
- **Controles de teclado** completos:
  - Espaço/K: Play/Pause
  - Setas: Pular 10 segundos
  - F: Fullscreen
  - M: Mute
- **Sugestão automática** da próxima história
- **Indicadores visuais** para histórias assistidas
- **Sistema de favoritos**
- **Tratamento de erros** elegante

### 🎵 Conteúdo de Mídia
- **Imagens em estilo Disney/Pixar** para todas as histórias
- **Roteiros de narração infantil** preparados
- **Estrutura para vídeos** demonstrativos
- **Capas personalizadas** para cada história

## 🛠️ Como Usar

1. **Abra o arquivo `index.html`** em qualquer navegador moderno
2. **Navegue pelas seções** usando o menu superior
3. **Use os filtros** para encontrar histórias por livro bíblico
4. **Clique em qualquer história** para assistir
5. **Use os controles do player** ou teclado para navegar

## 🎨 Personalização

O projeto foi desenvolvido para ser facilmente personalizável:
- **Cores e temas** podem ser alterados no `styles.css`
- **Novas histórias** podem ser adicionadas no `script.js`
- **Layout** pode ser modificado no `index.html`

## 📝 Notas Importantes

- **Vídeos**: O projeto inclui estrutura completa para vídeos, mas usa placeholders
- **Áudios**: Roteiros de narração estão prontos para gravação
- **Imagens**: Todas as imagens estão em alta qualidade estilo Disney/Pixar
- **Compatibilidade**: Funciona em todos os navegadores modernos
